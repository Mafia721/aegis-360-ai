# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ Yes    |

## Responsible disclosure

If you discover a security vulnerability **in aegis-360-ai itself** (e.g., RCE in the
Flask API, secret exposure, command injection in a helper), please report it
**privately** rather than opening a public GitHub issue.

### How to report

1. Email the maintainer at the address listed in the GitHub profile, **or**
2. Open a [GitHub Security Advisory](https://github.com/BinaryGalaxys/aegis-360-ai/security/advisories/new)

Include:
- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Your suggested fix (if any)

We aim to acknowledge reports within 48 hours and provide a fix or mitigation
within 14 days for critical issues.

## Scope

This policy covers only vulnerabilities in the aegis-360-ai framework code itself.
Vulnerabilities discovered **using** this tool against authorized targets should
be reported to the respective target's vulnerability disclosure programme.

## Legal

aegis-360-ai is for **authorized security testing only**. Any use against systems
you do not have explicit written permission to test is illegal and outside the
scope of this project.
